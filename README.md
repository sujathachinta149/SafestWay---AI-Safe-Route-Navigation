# SafeWay - AI Safe Route Navigation

SafeWay is an AI-assisted pedestrian
navigation website designed to help users
explore safer route options.

## Features

- Safest route selection
- Balanced route selection
- Fastest route selection
- Interactive map
- Emergency SOS demonstration
- Unsafe hazard reporting
- Safety score
- Street lighting information

## Technologies Used

- HTML
- CSS
- JavaScript
- Tailwind CSS
- Leaflet Maps

## How to Run

Open index.html in your browser.

## Important

Route scores, lighting values and locations
are sample demonstration data.
The SOS feature does not contact emergency
services.
